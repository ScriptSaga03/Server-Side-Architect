Spendwise API Documentation

Welcome! This is the backend API documentation. Please copy the full URLs below and use them in Postman or Thunder Client.

🔐 Authentication Routes

POST Register User
Register a new user account into the system.
Thunder Client / Postman URL:
http://localhost:5000/api/v1/auth/register
Required JSON Body Fields:
{ "username": "yourname", "email": "test@gmail.com", "password": "yourpassword" }
POST Login User
Authenticate user credentials and generate a JSON Web Token (JWT).
Thunder Client / Postman URL:
http://localhost:5000/api/v1/auth/login
Required JSON Body Fields:
{ "email": "test@gmail.com", "password": "yourpassword" }

💰 Expense Routes (Requires Bearer Token)

GET Get All Expenses
Fetch all expenses (Supports optional query filters like ?category=Food&sort=price-desc).
Thunder Client / Postman URL:
http://localhost:5000/api/v1/expenses
POST Create Expense
Log and create a new expense record.
Thunder Client / Postman URL:
http://localhost:5000/api/v1/expenses
Required JSON Body Fields:
{ "title": "Grocery", "amount": 500, "category": "Food", "paymentMethod": "UPI", "isRecurring": false }
GET Get Expense By ID
Retrieve details of a specific expense by its unique ID.
Thunder Client / Postman URL (Replace :id with actual MongoDB ID):
http://localhost:5000/api/v1/expenses/:id
PATCH Update Expense
Update an existing expense document.
Thunder Client / Postman URL (Replace :id with actual MongoDB ID):
http://localhost:5000/api/v1/expenses/:id
Required JSON Body Fields:
{ "amount": 600, "category": "Bills" }
DELETE Delete Expense
Delete a specific expense record by ID.
Thunder Client / Postman URL (Replace :id with actual MongoDB ID):
http://localhost:5000/api/v1/expenses/:id
PATCH Atomic Update
Apply high-level atomic operators ($inc, $addToSet, etc.) on specific fields.
Thunder Client / Postman URL (Replace :id with actual MongoDB ID):
http://localhost:5000/api/v1/expenses/atomic/:id
Required JSON Body Fields:
{ "amountDelta": 100, "addTag": "urgent" }
